# Custom Preset Designs

This folder is designed to store project `.json` configuration files. 

If any `.json` file is added to this directory, the system will dynamically detect it and generate a load button inside the **Preset Designs** (formerly *Wall Boundary Shape*) section on the **Canvas** tab.

### How it works:
1. Save your preset file here with a lowercase, underscore-separated name (e.g., `kitchen_backsplash.json` or `classic_shower_wall.json`).
2. The system automatically formats the file name into a button title (e.g., `Classic Shower Wall`).
3. Click the button to instantly configure your whole workspace.
4. You can still customize your dimensions and layout at any time after loading!
