# SESSION 45 SUMMARY — CLIENT ESTIMATOR & PUBLIC VIEWER REFINEMENTS

### 1. Client Link Preferences & Author Controls
* **Domain Types & State Management (`types.ts`, `projectSlice.ts`):**
  Added two new state flags to the global store: `publicShowQuantities` (boolean, default: `false`) and `publicShowPricing` (boolean, default: `false`), along with state updater actions (`setPublicShowQuantities`, `setPublicShowPricing`). These flags are automatically serialized, hydrated from Supabase project JSON snapshots, and reset during workspace clears.
* **Author Settings Panel (`CalibrationSettings.tsx`):**
  Added a new **CLIENT LINK PREFERENCES** card in the author's Settings tab (positioned directly above "Client Activity"). Features two toggles allowing authors to control whether public link visitors can view material quantities and optional pricing/costs. The pricing toggle automatically disables and greys out if quantities visibility is turned off.

### 2. Client-Facing Quantities & Estimator Suite
* **Dedicated Read-Only Presentation View (`ClientQuantitiesView.tsx`):**
  Created a presentation-only component displaying:
  * Design Area selection tabs (Project Totals, individual walls/accents).
  * Total Surface Area, Perfect Sheets/Tiles Used, Cut Sheets, Total Raw Equivalents, and Recommended Square Footage.
  * Static Calculation Method badge ("Strict Pieces" or "Reuse Cuts") without interactive toggles.
  * Read-only **Purchasing & Costs Estimator** table (conditionally rendered only when `publicShowPricing` is `true`), hiding all input fields and formatting prices as static currency.
* **Viewport Slide-Out Drawer (`ClientQuantitiesDrawer.tsx`):**
  Built a left-to-right animated slide-out drawer anchored strictly inside the canvas viewport container below the header bar. Includes a header with dynamic title and close (`X`) button, wrapping `<ClientQuantitiesView />` in a scroll-isolated container.

### 3. Public Viewer Header & Mobile Layout Refinements
* **Header UI Sanitization (`CanvasHeader.tsx`):**
  * Standardized `isPublicViewerMode` across `CanvasHeader.tsx` so URL-based links (`?view=cad`) behave identically to store-based public viewer states.
  * Removed status/sync dots, "CLOUD *" indicators, "LOCKED" badges, extra sub-area measurement text, and the "PUBLIC VIEWER" badge.
  * Added flexbox truncation (`min-w-0 flex-1 truncate`) to the project title so it shrinks gracefully on small screens.
* **Dynamic Header Trigger Button:**
  Added a responsive button on the right side of the black canvas header bar. Dynamically switches labels between **"View Estimate"** (if pricing is enabled) and **"View Quantities"** (if pricing is disabled).

### 4. Auto-Fit & Floating HUD Interaction Fixes
* **Viewport Auto-Fit framing (`useCanvasViewport.ts`):**
  Fixed asynchronous hydration conflicts in `useCanvasViewport.ts` so that `performAutoFit()` triggers as soon as `wallVertices` geometry finishes loading from Supabase and container DOM dimensions stabilize (`clientWidth >= 100px`), scaling public CAD links to fit the screen (~38% scale) on first load.
* **Floating HUD Controls (`ZoomControls.tsx`, `VisibilityMenu.tsx`, `FloatingToolbar.tsx`):**
  Added `pointer-events-auto z-50` and stopped pointer/touch event propagation (`onPointerDown`, `onTouchStart`, `onMouseDown`) on floating HUD elements. This prevents parent canvas gesture handlers and read-only interaction locks from intercepting clicks/taps on Zoom In/Out, Center/Bullseye Fit, and Layers controls.
* **3D Hinge Chains & Pivot Anchor Math (`HingeChains.tsx`):**
  - Corrected recursive position offsets in `LeftHingeChain` so that recursive child column origins anchor to `-columns[index + 1].d3Width` (the parent column's left edge / `startX`).
  - Preserved symmetric rotation sign conventions (`rotY = -foldAngleRad` for Right columns and `rotY = +foldAngleRad` for Left columns).
  - Outward Fireplace (-90°) folds and Inward Shower (+90°) folds now rotate cleanly around exact hinge boundaries without detachment or floating mesh artifacts.
* **3D Z-Axis Projection for Fireplace / Bump-Out Mode (`MainTileLayoutGroup.tsx`, `ImportedLayoutObject.tsx`):**
  - Dynamically detects outward folding side returns (foldAngle < 0, e.g., -90°).
  - Automatically shifts the main front wall panel forward along the Z-axis by `+outwardReturnDepth` (e.g. +12").
  - Ensures the front wall projects into the 3D room interior as a chimney breast, while the back edges of the side returns rest flush against the room's back drywall plane (`Z = 0`).

### 5. Continuous Fold Angle & 3D Fireplace Bump-Out Engine
* **Domain Types & Hinge State (`types.ts`, `draftingSlice.ts`):**
  Updated the `FoldLine` interface to support an optional `foldAngle?: number` property (in degrees, default: `90`). Added the `setFoldAngle` store action and updated serialization/hydration logic.
* **Wall Setup Authoring Control:**
  Added a global **"Layout Fold Type"** toggle switch in the Wall Setup sidebar: **"Shower / Alcove (Inward +90°)"** vs **"Fireplace / Bump-Out (Outward -90°)"**.
* **3D Hinge Matrix Math (`HingeChains.tsx`, `useD3Columns.ts`):**
  Updated 3D column segment math and hinge rotation calculations to convert `foldAngle` dynamically from degrees to radians. Mapped `foldAngle` onto column segments in `useD3Columns.ts` and corrected relative rotation signs across left (`+foldAngle`) and right (`-foldAngle`) hinges.
* **3D Z-Axis Forward Projection (`MainTileLayoutGroup.tsx`, `ImportedLayoutObject.tsx`):**
  In Bump-Out / Fireplace mode (`foldAngle = -90°`), the engine calculates the return depth (e.g., 12") and shifts the main front wall panel **forward into the room along the Z-axis by `+returnDepth`**. This cleanly projects the structure into the room interior as a 3D chimney breast while anchoring the back edges of the side returns flush against the room's back drywall wall plane (`Z = 0`).

### 6. 3D Niche Texture Backplate & Sub-Area Bounding Fixes
* **Isolated Sub-Area Texture Extraction (`NicheFeature.tsx`):**
  - Replaced shallow `globalTexture.clone()` calls (which suffer from WebGL offset/repeat clipping bugs on canvas textures) with isolated 2D sub-rectangle extraction onto dedicated offscreen canvases matching `ShelfFeature.tsx`.
  - Converted `useMemo` dependency arrays to use primitive coordinates (`bounds.minX`, `bounds.minY`, `bounds.width`, `bounds.height`) instead of volatile composite object references to prevent unnecessary texture regeneration and premature `dispose()` cycles.
  - Added support for custom slab surfaces (`surfaceUrl`) and realistic physical roughness/metalness parameters on recessed niche backings.

### 7. File Loading & Startup Performance Optimization (Phase 1)
* **Lazy On-Demand Print Set Preloading (`printSetManager.ts`):**
  - Converted `printSetManager.ts` from eager startup instantiations of `new Image()` for every print set to an on-demand preloader and memory cache (`preloadPrintSet`).
  - Available set names and file URLs remain synchronous and fast, but DOM image decodes only fire when a set is actively rendered or selected by the user.
  - Redraw notifications are dispatched cleanly to `setIsCanvasDirty` only when active assets finish loading.
